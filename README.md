# Погода

Короткий прогноз в одном экране: температура сейчас, что надеть, осадки за день и когда станет теплее. Кнопка внизу открывает семь дней, круглая кнопка — поиск города. Город по умолчанию — Самара, выбор сохраняется в браузере.

Данные приходят из [Open-Meteo](https://open-meteo.com/) без ключа.

## Запуск

```bash
npm install
npm run dev
```

Сервер разработки: http://127.0.0.1:4321

## Сборка

```bash
npm run build
npm run preview
```
