# CardioAssist

Вспомогательное мобильное веб-приложение для кардиолога: калькуляторы шкал, измерение интервалов на фото ЭКГ и локальная картотека. Это инструмент поддержки решений, а не диагностическое ПО.

Сейчас готовы каркас и оболочка: нижняя навигация, светлая и тёмная темы, русские тексты через vue-i18n и дисклеймер при первом запуске. Калькуляторы, измерение ЭКГ и картотека появятся следующими шагами.

## Дисклеймер

CardioAssist не ставит диагноз, не назначает лечение и не является медицинским изделием. Он не заменяет клиническое решение врача. Пороги и коэффициенты шкал нужно сверять с актуальными клиническими рекомендациями.

## Данные пациентов

Не коммитьте реальные данные пациентов. В репозитории не должно быть выгрузок картотеки, фотографий ЭКГ, PIN-кодов и паролей экспорта. У приложения нет сервера: когда появится картотека, записи останутся в браузере устройства. Очистка данных браузера их удалит.

## Запуск

Нужен Node.js 22.

```bash
npm install
npm run dev
```

Сервер разработки: http://127.0.0.1:4321

При первом открытии приложение показывает дисклеймер и не пускает дальше, пока его не подтвердят. Выбор темы сохраняется в браузере.

```bash
npm test
npm run lint
npm run build
npm run preview
```

## Структура

```text
src/features/calculators   шкалы, чистая логика в logic/
src/features/ecg           измерение ЭКГ по фото
src/features/patients      локальная картотека
src/features/settings      тема и параметры устройства
src/shared                 общие компоненты и настройки приложения
src/router                 Vue Router, режим hash
src/stores                 Pinia
```

Логика калькуляторов не зависит от Vue. Интерфейс на русском; строки позже уедут в vue-i18n.

## Деплой на GitHub Pages

Workflow `.github/workflows/pages.yml` запускается при пуше в `main`: установка, тесты, линт, проверка форматирования, сборка и публикация.

Базовый путь берётся из имени репозитория (`VITE_BASE=/<имя репозитория>/`), поэтому проектный сайт открывается по адресу `https://<пользователь>.github.io/<репозиторий>/#/`. Локально `VITE_BASE` не задан, и `base` равен `/`.

В настройках репозитория для Pages выберите источник **GitHub Actions**. Маршруты в режиме `hash`, отдельные серверные редиректы не нужны.

Шрифт Inter подключён локально: в сборку входят только woff2 для латиницы и кириллицы. Внешних API, аналитики и трекеров нет.
