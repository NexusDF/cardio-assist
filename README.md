# CardioAssist

Вспомогательное мобильное веб-приложение для кардиолога: калькуляторы шкал, измерение интервалов на фото ЭКГ и локальная картотека. Это инструмент поддержки решений, а не диагностическое ПО и не медицинское изделие.

Интерфейс на русском. Тексты собраны в `src/shared/i18n/ru.ts`, чтобы позже добавить другой язык.

## Возможности

- Шкалы QTc (Bazett, Fridericia, Framingham, Hodges), CHA₂DS₂-VASc, HAS-BLED и HEART. Пороги лечения, которые не сверены с рекомендациями, на экран не выводятся.
- Снимок ЭКГ с камеры или из галереи: масштаб на устройстве, циркуль для RR, PR, QRS и QT, ЧСС и QTc по тем же формулам.
- Карточки в IndexedDB: код вместо фамилии, возраст, пол, заметка, результаты шкал и снимки.
- Графики QTc Bazett и ЧСС по сохранённым измерениям.
- Архив JSON, зашифрованный паролем на устройстве (PBKDF2 и AES-GCM). Импорт добавляет только новые записи.
- Необязательный PIN после обновления страницы и удаление всех карточек, результатов, снимков и черновиков.
- Установка на домашний экран. После первой загрузки оболочка открывается без сети.

## Дисклеймер

CardioAssist не ставит диагноз, не назначает лечение и не заменяет клиническое решение врача. Пороги и коэффициенты шкал нужно сверять с актуальными клиническими рекомендациями. При первом запуске приложение не пускает дальше, пока это не подтвердят. Тот же текст есть в разделе «О приложении».

## Данные пациентов

Не коммитьте реальные данные пациентов. В репозитории не должно быть выгрузок картотеки, фотографий ЭКГ, PIN-кодов и паролей архива.

Сервера нет: карточки, снимки и черновики шкал остаются в браузере устройства. Очистка данных сайта их удаляет. Пароль архива приложение не хранит. Тема и PIN при удалении карточек остаются.

## Офлайн

Service worker кэширует оболочку. Когда она готова работать без сети, приложение показывает это один раз. Пока сети нет, наверху остаётся напоминание: расчёты и карточки по-прежнему на этом устройстве. IndexedDB не требует сети. Скачанный архив — обычный файл, его нужно хранить отдельно.

## Запуск

Нужен Node.js 22.

```bash
npm install
npm run dev
```

Сервер разработки: http://127.0.0.1:4321

```bash
npm test
npm run lint
npm run build
npm run preview
```

Выбор темы сохраняется в браузере. Маршруты в режиме `hash`.

## Структура

```text
src/features/calculators   шкалы, чистая логика в logic/
src/features/ecg           измерение ЭКГ по фото
src/features/patients      картотека, графики, IndexedDB
src/features/settings      тема, архив, PIN, удаление данных
src/shared                 общие компоненты, офлайн и тексты
src/router                 Vue Router, режим hash
src/stores                 Pinia
```

Логика шкал, измерений, архива и PIN не зависит от Vue и покрыта тестами Vitest.

## Деплой на GitHub Pages

Workflow `.github/workflows/pages.yml` запускается при пуше в `main`: установка, тесты, линт, проверка форматирования, сборка и публикация.

Базовый путь берётся из имени репозитория (`VITE_BASE=/<имя репозитория>/`), поэтому проектный сайт открывается по адресу `https://<пользователь>.github.io/<репозиторий>/#/`. Локально `VITE_BASE` не задан, и `base` равен `/`.

В настройках репозитория для Pages выберите источник **GitHub Actions**. Отдельные серверные редиректы не нужны.

Шрифт Inter подключён локально: в сборку входят только woff2 для латиницы и кириллицы. Внешних API, аналитики и трекеров нет.
